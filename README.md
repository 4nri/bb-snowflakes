# BetBoom · Snow Lab

[Открыть демо](https://4nri.github.io/bb-snowflakes/) · [Макеты Figma](https://www.figma.com/design/mZPIQ2poXiuRzyO4JU2nPS/BB---2026?node-id=7596-3042)

Два исходных макета 393 × 852 рядом, анимированный снег поверх каждого и общая панель настройки. Макеты экспортированы из Figma в PNG; интерфейс акции в стенде статичен.

## Возможности

- Количество, размер и непрозрачность простых круглых точек.
- Скорость падения, ветер в обе стороны, покачивание.
- Три пресета: лёгкий снег, снегопад, метель.
- Снег по всему контенту или только на иллюстрации. Шапка и системные панели исключены.
- Пауза, выключение, масштаб, полноэкранный просмотр. Целевая частота 60 FPS.
- Экспорт/импорт JSON, ссылка с текущими настройками, сохранение в браузере.
- На узких экранах макеты остаются рядом и доступны горизонтальной прокруткой; настройки расположены ниже.

На стартовом макете уже нарисованы снежинки. Они входят в исходный PNG и остаются видны при выключении анимации. Для чистого сравнения эффекта используйте правый макет или замените левый экспортом без статичного снега.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов и сборка не требуются.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run check
```

Для размещения на любом статическом хостинге достаточно `index.html`, `styles.css`, `src/`, `assets/`. GitHub Pages публикует корень ветки `main`.

## Интеграция

Скопируйте только **`src/snow.js`** в свой проект. Стенд, PNG, панель и другие файлы модулю не нужны. Runtime-зависимостей нет.

```html
<div class="scene" id="scene">
  <!-- Контент вашего приложения -->
</div>
<style>
  .scene { position: relative; overflow: hidden; }
</style>
<script type="module">
  import { Snow } from './snow.js';

  const host = document.querySelector('#scene');
  const snow = new Snow(host, {
    count: 40,
    size: 2,
    speed: 28,
    wind: 6,
    sway: 10,
    opacity: 0.65,
    enabled: true
  }, { referenceWidth: 393 });

  snow.update({ wind: -20 });
  // snow.setClip(98, 818); // верхняя и нижняя границы в координатах макета
  // snow.pause();
  // snow.play(); // учитывает prefers-reduced-motion
  // snow.destroy(); // вызывайте при размонтировании
</script>
```

`referenceWidth` задаёт ширину системы координат, по умолчанию 393. Размеры и скорость сохраняют пропорции при масштабировании контейнера. Для другого макета передайте его исходную ширину. Высота берётся из пропорций контейнера. Размер контейнера должен быть задан контентом или CSS.

Canvas располагается поверх контента, не перехватывает клики и скрыт от скринридера. При сложной структуре слоёв задайте своему контейнеру `isolation: isolate` и нужный `z-index` для canvas.

### Настройки

| Ключ | Значение по умолчанию | Диапазон / смысл |
| --- | --- | --- |
| `count` | 40 | 0–200 частиц на один контейнер, включая частицы вне области отсечения |
| `size` | 2 | 0.5–6, базовый радиус в px; размер меняется с глубиной |
| `speed` | 28 | 0–160 px/с, базовая скорость, зависит от глубины |
| `wind` | 6 | −100…100 px/с, минус влево |
| `sway` | 10 | 0–60 px, амплитуда покачивания |
| `opacity` | 0.65 | 0–1, максимальная непрозрачность |
| `enabled` | true | Выключение скрывает анимацию |

`normalize()` проверяет и ограничивает внешние значения. Неизвестные поля игнорируются, некорректные значения заменяются стандартными.

### Использование JSON из стенда

Файл содержит `{ version, settings, area }`. Передайте `settings` в конструктор. `area` относится к двум макетам стенда; для своего интерфейса задайте границы через `setClip(top, bottom)`.

```js
const config = await fetch('./bb-snow-settings.json').then(r => r.json());
const snow = new Snow(host, config.settings, { referenceWidth: 393 });
```

### Движение и ресурсы

Один общий `requestAnimationFrame` для всех экземпляров. На каждом экране один Canvas. Все точки рисуются одним общим путём и одним вызовом `fill()`. Текстур, изображений частиц, размытия и покадровых CSS-фильтров нет. Буфер имеет DPR 1, в том числе на Retina: декоративный слой не требует увеличения числа пикселей в 4–9 раз. По умолчанию 40 точек на экран, 80 на весь стенд. Общий планировщик ограничивает отрисовку 60 кадрами в секунду без накопления ошибки таймера.

Модуль останавливает кадры, если вкладка скрыта, контейнер вне видимой области, включена пауза, эффект выключен или количество равно нулю. Движение рассчитывается по времени, а шаг после задержки ограничен 50 мс. Поэтому возвращение во вкладку не вызывает скачка снега.

`prefers-reduced-motion: reduce` останавливает модуль по умолчанию. После явного действия пользователя можно вызвать `snow.play({ ignoreReducedMotion: true })`. В стенде это кнопка «Запустить».

FPS в нижней строке измеряется по фактическим кадрам одного активного экрана. Рядом показано время расчёта и отрисовки одного экрана (95-й процентиль последних 240 замеров обоих экранов). Замеры подключены только в стенде через необязательный `onFrame` в options; самостоятельный модуль по умолчанию их не собирает. Это диагностическое значение, а не гарантия скорости на любом устройстве. Размер модуля и результаты проверок: [docs/status.md](docs/status.md).

## Файлы

- `src/snow.js`: самостоятельный модуль анимации.
- `src/app.js`: контролы стенда, конфигурация, просмотр макетов.
- `assets/start.png`, `assets/main.png`: экспорты узлов `7596:3043`, `7596:4131` из Figma.
- `tests/snow.test.js`: проверка внешних параметров и расчёта движения.
