# План

Цель: лёгкий снег поверх двух макетов Figma, настройка поведения и публикация на GitHub Pages.

## Допущения
- Макеты используются как статические изображения; интерактивен снег и стенд.
- Репозиторий 4nri/bb-snowflakes, публикация на GitHub Pages.
- Vanilla JS, Canvas 2D, без runtime-зависимостей и сборки.

## Этапы
- [x] Экспорт двух экранов 393 × 852 из Figma. Готово: локальные изображения без временных URL. Проверка: размеры и визуальное соответствие. При ошибке экспорта исправить до публикации.
- [x] Модуль снега и стенд. Готово: общие контролы, пресеты, пауза, выключение, экспорт/импорт JSON, ссылка с настройками, адаптивный просмотр. Проверка: node --test и браузер. При ошибке остановить публикацию.
- [x] Документация и GitHub Pages. Готово: исходники в репозитории, инструкция интеграции, работающий URL. Проверка: HTTP и опубликованный стенд.

Уточнение пользователя: производительность на слабых устройствах важнее детализации. Только простые точки, DPR 1, пакетная отрисовка, без режима 30 FPS.

## Проверка CPU throttling
- [x] Воспроизводимые замеры ×1, ×4, ×6, ×10: модуль на мобильном экране, полный стенд и контроль без снега. Измерять реальные интервалы кадров эффекта, пропуски и CPU-время; не ограничиваться средним FPS.
- [x] Исправить подтверждённые причины пропусков, повторить затронутые сценарии.
- [x] Сохранить отчёт, исходные результаты и проверяемый сценарий в репозитории; опубликовать изменения.
