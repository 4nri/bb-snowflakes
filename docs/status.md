# Статус

Фаза: завершено.

## Готово

- Два исходных PNG из Figma, по 393 × 852, узлы 7596:3043 и 7596:4131.
- Стенд с общими контролами, пресетами, паузой, выключением, масштабом, полноэкранным режимом, экспортом/импортом JSON и ссылкой с настройками.
- Самостоятельный Canvas-модуль без зависимостей.
- После уточнения пользователя оставлены только простые круглые точки. Удалены кристаллы, спрайты и настройка 30 FPS. По умолчанию 40 точек на экран, целевая частота 60 FPS.
- Одна заливка на Canvas, DPR 1 даже на Retina. Никаких текстур и фильтров. Один общий планировщик.
- GitHub-репозиторий: https://github.com/4nri/bb-snowflakes

## Проверки

- `npm run check`: успешно.
- `npm test`: 7 тестов успешно. Проверены границы настроек, нулевые значения, движение по времени, повтор частиц, остановка для hidden/reduced-motion/невидимого контейнера и очистка ресурсов.
- Браузер: оба PNG загружены в исходном размере, два Canvas, нет ошибок консоли. Проверены пресеты, пауза/выключение, область, экспорт и импорт JSON, ссылка и восстановление параметров, полноэкранный режим.
- Мобильная ширина 390 px: общий документ не шире viewport; макеты в отдельной горизонтальной прокрутке, контролы ниже.
- `src/snow.js`: 6330 байт исходного текста, 2338 байт gzip. Стенд не требует сборки.
- Лёгкий пресет в локальном браузере: 80 точек на два экрана, наблюдалось 57 FPS; пресет «Метель» с 220 точками показал 60 FPS; 95-й процентиль CPU-времени расчёта и отправки команд Canvas одного экрана около 0.10 мс. Время растеризации/композиции GPU в это число не входит. Это замер среды разработки, не результат на физическом слабом телефоне.
