# Проверки

- node --test: нормализация внешних настроек, границы значений, генерация и шаг частиц, независимость движения от частоты кадров.
- Браузер: оба изображения загружены, снег меняется контролами, пауза/возобновление, выключение, пресеты, JSON, ссылка с настройками, полноэкранный режим.
- Узкий экран: оба макета доступны горизонтальной прокруткой, контролы доступны с клавиатуры.
- Доступность: reduced-motion по умолчанию останавливает снег, canvas не перехватывает указатель; остановка при скрытой вкладке и выходе из области видимости.
- Перед публикацией: нет временных URL и секретов, загрузка без внешних runtime-зависимостей, HTTP 200 опубликованной страницы.

- Производительность: одна заливка для всех точек, DPR 1, 40 точек на экран по умолчанию; замер CPU-времени эффекта отдельно от FPS страницы. Тест на физическом слабом телефоне не проводился.
