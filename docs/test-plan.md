# Проверки

- node --test: нормализация внешних настроек, границы значений, генерация и шаг частиц, независимость движения от частоты кадров.
- Браузер: оба изображения загружены, снег меняется контролами, пауза/возобновление, выключение, пресеты, JSON, ссылка с настройками, полноэкранный режим.
- Узкий экран: оба макета доступны горизонтальной прокруткой, контролы доступны с клавиатуры.
- Доступность: reduced-motion по умолчанию останавливает снег, canvas не перехватывает указатель; остановка при скрытой вкладке и выходе из области видимости.
- Перед публикацией: нет временных URL и секретов, загрузка без внешних runtime-зависимостей, HTTP 200 опубликованной страницы.

- Производительность: одна заливка резких точек, мягкие точки из общего кэша, DPR 1, 40 точек на экран по умолчанию; замер CPU-времени эффекта отдельно от FPS страницы. Тест на физическом слабом телефоне не проводился.

## CPU throttling

- `scripts/benchmark.mjs`: отдельный Chrome, CDP Emulation.setCPUThrottlingRate.
- CPU ×1/×4/×6/×10. Модуль: viewport 393 × 852, DPR 3, Canvas DPR 1; 40/110/200 точек. Полный стенд: два экрана, до 400 точек.
- Два независимых измерения: кадровый цикл браузера и фактические вызовы отрисовки Canvas. Учитывать 95/99-й перцентили интервала, максимальный интервал, минимальный FPS в скользящем окне 1 с, паузы >25/>50 мс.
- Контроль со снегом, выключенным полностью. Проверять применённые параметры каждого сценария.
- После исправления повторить всю матрицу и длительные сценарии ×6/×10, включая изменение контролов.
- Регрессионный тест: 59.94/60/60.1/61 Hz без искусственного пропуска кадра; 75/90/120/144 Hz сохраняют ограничение около 60 отрисовок в секунду.
- Предел вывода: замедление CPU относительно этого компьютера; реальный GPU, нагрев и энергосбережение слабого телефона не эмулируются.

## Сравнение старого проекта

- `scripts/compare-legacy.mjs`: старый файл по закреплённому commit с проверкой SHA-256, одинаковый мобильный viewport и CPU ×1/×6/×10.
- Отдельно исходные настройки, одинаковые 40/200 точек, размытие, скрытие панели и ноль частиц. Сохранять фактически применённую конфигурацию.
- Три парных повтора для 200 точек при ×10, чередовать порядок вариантов. Стандартные нагрузки дополнительно измерить по 20 секунд.
- Считать кадры общего цикла, а не суммировать три старых Canvas. CPU-время включает обёртку измерений и отправку команд; GPU-время не измеряется.
- Отчёт и полные данные: docs/legacy-comparison.md и docs/legacy-comparison-data.json. Сравнение завершено; превосходство нового алгоритма при одинаковом числе точек не подтверждено.

## Параллакс и разброс размеров

- Нормализация `sizeVariation`: 0–1, конечные значения; отсутствие поля в старом JSON использует стандартное значение.
- При 0 точки одинаковые по радиусу и скорости. При 1 крупная точка до четырёх раз больше и быстрее мелкой. За секунду перемещение совпадает при 30/60 FPS.
- Изменение разброса сохраняет частицы, координаты и случайную глубину; после 0 → 1 восстанавливается прежнее распределение. Новые частицы учитывают текущий разброс.
- Браузер: контрол и подпись в процентах, обновление во время паузы, JSON экспорт/импорт, старая ссылка без нового поля, сохранение после перезагрузки, клавиатура и мобильная ширина 393 px.
- CPU ×6/×10: один мобильный экран 200 частиц, два экрана 400; нулевой и максимальный разброс, изменение регулятора с сохранением настроек. Сохранить фактические параметры и интервалы кадров. Результат относится к CPU-эмуляции.
- Повторить проблемные жесты по 30 секунд, сравнить с контролом ветра, учитывать независимый кадровый цикл браузера и длительность обработчиков input/change.
- После переноса автосохранения проверить немедленную перезагрузку, сброс записи на pagehide, fallback без requestIdleCallback и приоритет параметров новой входящей ссылки.

## Размытие по глубине

- Нормализация blur 0–1; старые JSON и ссылки; сохранение через экспорт, импорт, reload, share. Регулятор с клавиатуры, подпись процентов, видимость макетов на мобильном.
- blur 0: прежняя общая заливка, без создания текстур. Средние частицы резкие, дальние и ближние мягкие; дальние слабее ближних. Изменение blur не меняет координаты, глубину и движение; на паузе применяется сразу.
- Общий ограниченный кэш мягких точек; настройка силы/размера/разброса не создаёт текстуру каждый кадр. Клип учитывает мягкий край. Остановка при reduced-motion, скрытии, count 0, уничтожении.
- CPU ×6/×10: два макета 80/400 частиц и один экран 393 × 852 с 200; радиус 2/6, blur 0/0.4/1, разброс 0/1, жесты blur/size. Длинные повторы максимума. Сравнить независимые кадры и фактическую отрисовку, p95 CPU и паузы >25/50 мс. Полные данные сохранять, пропуски исследовать.
- Перед публикацией npm test, npm run check, браузерные проверки blur/parallax/design; после публикации проверка контролов и совпадения файлов.

## Типографика и отступы

- Реальные прямоугольники текста трёх нижних действий совпадают по вертикали с допуском 0.5 px. Подписи и численные значения помещаются в контрол; подсказки переносятся внутри блока.
